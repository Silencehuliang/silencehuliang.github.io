## 前言

2020 年，注定是被写进历史的一年。对我个人来说，这一年也发生了不少值得记录的事。

## 疫情之下

年初武汉封城，我写了两篇文章记录心情（[武汉封城了](/武汉封城了/)、[新冠感想](/新冠感想/)）。那段时间的焦虑、感动和 reflection 现在回看依然清晰。这一年最大的感悟是：健康和身边的人，比什么都重要。

## 博客

今年年初把博客彻底重构成了 Hugo，就是现在看到的这个样子，顺便把之前的文章都搬迁了过来。这一年写了 Python 学习之路系列、爬虫系列、接口测试系列，输出了不少内容。写博客这件事，最大的受益者其实是自己——很多东西写着写着才算真正想明白。

## 工作

今年在工作中做的几个小项目都沉淀到了 GitHub 上：多账号查询系统、股票新闻抓取（StockNews）、小亮商店等等。技术栈还是 Python 那一套，接口测试方面深入了不少，JMeter 系列文章就是这一年整理的。
