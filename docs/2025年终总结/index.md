# 2025年终总结


## 前言

2025 年的关键词是:**边缘计算与 AI**。这一年我部署了一堆小服务，全部跑在免费额度上，零服务器零运维;同时 AI 编码从"辅助"开始走向"主力"。

## 自部署小服务盘点

- **filehelper**:匿名的文件传输助手，手机电脑之间传文件不用再开微信
- **openai-gemini**:把 OpenAI 接口格式转成 Gemini 的转换器，一堆只认 OpenAI 格式的客户端都能吃到 Gemini
- **Gemini 代理**:先后部署了 gemini-balance 和它的边缘函数轻量版，聚合多个免费 Key 做负载均衡，AIStudio 的免费额度终于能稳定用起来
- **MoeMail 临时邮箱**:基于 NextJS + Cloudflare 自部署，注册验证再也不用担心隐私
- **spectrometer_gui**:给光谱仪写的数据处理 GUI(Python),帮工作提效的小工具

这一年的产出写在了一篇文章里:[白嫖边缘计算:2025年我自部署的小服务](/白嫖边缘计算-2025年我自部署的小服务/)。

## 技术转变

这一年我的"默认技术栈"完成了切换:**Cloudflare Workers + Hono + D1 + R2** 处理后端，**TypeScript** 处理前端。原来一台 VPS + Django 的架构，被边缘函数全面替代。个人开发者部署服务的成本无限趋近于零，这是我今年最深的体感。

AI 方面，编码工作流里 AI 的参与度从"查资料、写片段"提升到了"独立完成小模块"，人做的更多是设计和 review。
