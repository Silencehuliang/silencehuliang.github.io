# 2024年终总结


## 前言

如果用一句话总结 2024 年，那就是:**AI 离我的工作越来越近了**。

## 折腾记录

今年公开的产出不多，但折腾了不少：

- 部署了 **docker_image_pusher**（基于技术爬爬虾的开源项目），用 GitHub Actions 把国外 Docker 镜像转存到阿里云，彻底解决了国内服务器拉镜像的问题。原理和踩坑记录成了今年唯一一篇博客文章
- 工作之余开始系统接触 AI 编码工具，从最开始的辅助补全，到后来把相当一部分编码工作交给 AI

现在回头看，2024 年更像是"前夜"：工具已经在变强，但我的工作流还没被真正重塑。
