# 我的家庭数字工具箱:2026年给自己家造的软件


## 前言

写完 CoinNote(家庭记账小程序)之后，我发现根本停不下来——家里的各种"数字化需求"一个个冒出来。2026 年上半年，我陆陆续续给家里造了一整套软件，这篇文章做个汇总。

## 工具箱清单

### FamilyAssetManagement:家庭资产管理

基于 Cent 的"数据自持"理念做的一个家庭共享记账/资产管理 Web PWA：

- **数据完全自持**:账本就是一个 GitHub 私有仓库，数据以 JSON 纯文本存放，git 历史就是备份与回滚
- **家人友好**:家人不需要 GitHub 账号，管理员创建成员账号，打开网页输用户名密码就能用
- **离线优先**:PWA + 本地缓存，没网也能记账，联网自动同步
- **部署于 Cloudflare**，成本为零

"数据自持"是这一批工具的共同理念：不把家庭数据放在任何一家公司的服务器上，纯文本 + git，想迁移随时打包走人。

### family-budget:家庭预算

管钱这件事，记账是"记录过去"，预算是"约束未来"。family-budget 做的是每月预算的编制与跟踪：分类预算、执行进度、超支预警。TypeScript 编写，同样部署在 Cloudflare 上。

### Goal-Dashboard:目标看板

把工作组组织成**目标看板**的 DeepSeek Harness(DSH)插件，并集成了 mattpocock/skills 的工程工作流。简单说就是：把家庭/个人的目标拆成任务卡片，在桌面上有一个可视化看板随时看到进展。这是我第一个给 agent 工具链写插件的项目，后面 AI 工作流的文章里会详细聊。

### silence_tools:工具箱

一些日常小工具的合集，算是不值得单独开项目的东西的"杂物间"，比如各种一次性的格式转换、查询小页面。

### AiEnvManager

管理我的各种 AI 开发环境的配置小工具，把模型、Key、代理等环境配置统一管理切换，配合 2025 年搭的那一摊代理服务使用。

## 一点感悟

回头看这一批项目，有几个共同的点：

1. **需求都来自真实生活**:没有一个是"为了做个项目而做"，都是先有真实痛点
2. **技术栈高度收敛**:TypeScript + Cloudflare 全家桶，一个技术栈吃遍所有场景
3. **AI 深度参与**:这些项目的开发过程中，AI 编码助手的参与度越来越高，从"补全代码"进化到"理解需求、动手实现、跑测试"
4. **成本为零**:所有东西都跑在免费额度里，数据在自己手里

以前觉得"给家里做个软件"是一件需要攒很久技术的事，现在发现，缺的从来不是技术，是把生活里的痛点识别出来、然后动手解决的那股劲。

接下来计划把这套工具箱的公共部分(账号体系、同步机制)抽成一个底座，新工具的开发成本会进一步降低。到时再写。
