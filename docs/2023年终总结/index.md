# 2023年终总结


## 前言

2023 年是我技术栈发生明显转向的一年：**从纯 Python 后端，转向了 TypeScript 全栈**。趁着年底，把这一年记录一下。

## 技术转型

这一年为了做项目，系统地入了前端的坑：

- 托管并研究了 **vue-pure-admin**（vue-pure-admin 官方精简版），把 Vue3 + TypeScript + Vite 这套组合拳学了个遍
- 基于它做了一个支持配置的**后台管理系统**（CURD-Demo），表格、表单、权限、菜单这些后台系统的标配功能算是吃透了
- 顺手整理了自己的**图片床**（Picture_bed）和开发工具合集（DevelopmentTools）

从 Django 到 Vue，最不适应的不是语法，而是生态：npm 的版本地狱、组件库的选型、前端工程化的琐碎。熬过最开始的两个月之后，全栈开发的自由度确实让人上瘾。

## 项目

- **bilihuli**:年初把去年开始的弹幕视频网站做完了收尾（Django 后台），算是给自己 Python 时代画了个句号
