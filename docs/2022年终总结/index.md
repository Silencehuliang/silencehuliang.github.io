# 2022年终总结


## 前言

博客依然处于停更状态，但代码没有停。2022 年写了几个小项目，趁着年底补一篇总结。

## 项目

今年在 GitHub 上留下了三个小东西：

- **TimeSequence**:时间序列相关的小项目
- **PatternCodeGenerator**:一个模式代码生成器，做成了 VSCode 插件——写重复样板代码的时候让插件代劳，算是把"程序员消灭自己的重复劳动"这句老话落到实处
- **my-darling**:一个送给另一半的小项目，具体是什么就不写了，保密 :)

## 技术

这一年的关键词是「在工作之外保持手感」。虽然博客没更新，但业余时间一直在写代码。工具在变（VSCode 插件开发用到了 Node.js 和 TypeScript），主力语言还是 Python。
